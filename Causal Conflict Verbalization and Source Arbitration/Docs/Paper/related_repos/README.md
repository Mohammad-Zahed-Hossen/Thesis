- Excluded everywhere: `.git/`, `__pycache__/`, `.venv/`, `node_modules/`, images/binaries/datasets (`.png`, `.jpg`, `.pdf`, `.parquet`, `.jsonl`, `.csv`, `.tsv`, `.pt`, `.bin`, `.safetensors`, `.zip`), source/doc files `>= 500 KB`, and `.json` files `>= 100 KB`.
